### 实用工具

#### `noncopyable`
+ `noncopyable`允许程序轻松地实现一个禁止拷贝的类
  + 需要包含头文件`<boost/noncopyable.hpp>`
+ 当在`C++`中定义一个类时，如果不明确定义拷贝构造函数和拷贝赋值操作符，编译器会为自动生成这两个函数
  + 通常这些生成内容会自动支持`swap()`、符合容器拷贝语义、可以放入标准容器处理
+ 但是有时我们不需要类的拷贝语义，这时候可以禁用拷贝实例，私有化拷贝操作
  + 譬如`scoped_ptr`便通过这样的方式禁止了拷贝操作
  + 但是这样会导致代码存在大量信息量少的冗余，而`noncopyable`就解决了这一问题
+ `noncopyable`内部将自己的拷贝构造函数以及`=`的拷贝赋值运算符重载于私有方法中，以此在派生时防止拷贝
<br>

#### `ignore_unused`
+ 排除编码过程中暂时未用变量的警告
  + 需要包含头文件`<boost/core/ignore_unused.hpp>`
+ 支持任意数量、任意类型的变量，将参数临时使用，解除警告
+ 实现时使用`inline`函数，运行时完全没有效率损失
  ```c++
  template <typename... Ts>
  inline void ignore_unused(Ts const& ...) {}
  ```
<br>

#### `optional`
+ 在实际开发中，开发者经常会遇到无效值情况
  + 比如：函数即使正确执行，其结果却不是合理值
  + 这种情况于数学语言解释，这种情况就是返回值位于函数解空间之外
